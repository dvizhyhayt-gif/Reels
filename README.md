# TezTap MVP

Стартовый MVP сервиса быстрых подработок на чистом HTML, CSS и JavaScript.

## Что уже есть
- Регистрация и вход по телефону и паролю.
- Выбор роли: заказчик или исполнитель.
- Демо-подтверждение кода: пока используйте фиксированный код `1234`.
- Личный кабинет с фото, логотипом, ID профиля и заявкой на верификацию.
- Публикация заказов с адресом, временем, оплатой, фото и описанием.
- Лента заказов, отклики исполнителей, торг по цене и принятие отклика.
- Логика комиссии 10%, баланс аккаунта, долг по комиссии и блокировка следующего заказа.
- Локальное демо-хранилище с готовой точкой подключения Firebase.

## Структура
- `index.html` — интерфейс.
- `css/styles.css` — стили и адаптив.
- `js/app.js` — бизнес-логика MVP.
- `js/firebase-service.js` — временное хранилище и место для интеграции Firebase.
- `js/firebase-config.example.js` — пример конфига Firebase.
- `app.webmanifest` — задел под PWA и будущую упаковку.

## Как запустить
1. Открыть `index.html` в браузере.
2. Зарегистрировать аккаунт с любым кодом подтверждения.
3. Заполнить профиль и протестировать роли заказчика и исполнителя.

## Что подключим следующим этапом
- Firebase Auth для реального входа.
- Firebase Firestore для пользователей, заказов и откликов.
- Firebase Storage для фото профиля и фото заказов.
- SMS-код через Firebase Phone Auth.
- WhatsApp-код через отдельного провайдера, если он действительно нужен.
- Развёртывание на хостинг и упаковка в APK/PWA.

## Важно
Сейчас пароль и данные живут только в `localStorage` браузера. Для продакшена нужно будет перевести всё на Firebase и нормальную серверную логику правил доступа.

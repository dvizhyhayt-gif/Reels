AYUVERSE

Локальный запуск:
  node server.js
  http://localhost:3000

Данные аккаунтов, игр, статистики и модерации хранятся в Firebase.
ZIP-архивы и изображения игр хранятся в Supabase.
Публикация одобренных HTML-игр выполняется через Netlify Functions.

Перед обновлением сайта опубликуйте firestore.rules и загрузите весь проект в GitHub.

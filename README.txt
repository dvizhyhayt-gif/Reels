AYUVERSE — текущий этап

Структура:
  index.html
  css/style.css
  js/app.js
  server.js
  data/users.json

Запуск:
  node server.js
  http://localhost:3000

Сейчас реально работают:
- регистрация и вход;
- безопасное хеширование пароля через Node scrypt;
- HttpOnly-сессия;
- профиль игрока;
- избранное;
- история последних игр;
- live online сайта и игр;
- две демонстрационные HTML5-игры.

Важно:
- users.json используется как лёгкое локальное хранилище на этапе разработки;
- перед публичным запуском заменяем его на настоящую БД и включаем HTTPS;
- секреты в клиентский JS не помещаем.

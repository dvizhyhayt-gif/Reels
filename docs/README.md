# Reelgram

Полнофункциональное веб-приложение: сервис коротких вертикальных видео с записью, комментариями, лайками и профилем пользователя.

## 📁 Структура проекта

```
Reelgram/
├── index.html                 # Основной HTML файл
├── css/
│   ├── variables.css         # CSS переменные и базовые стили
│   ├── layout.css            # Основная разметка и контейнеры
│   ├── navigation.css        # Стили навигации и нижней панели
│   ├── feed.css              # Стили ленты видео
│   ├── video-overlay.css     # Стили оверлея видео (не, аватары, кнопки)
│   ├── search.css            # Стили поиска
│   ├── auth.css              # Стили аутентификации
│   ├── upload.css            # Стили загрузки и камеры
│   ├── profile.css           # Стили профиля пользователя
│   ├── comments.css          # Стили комментариев
│   └── components.css        # Стили компонентов (модали, уведомления)
├── js/
│   ├── data-service.js       # Управление данными и логика
│   ├── view-renderer.js      # Создание и рендеринг UI элементов
│   └── app.js                # Основное приложение и события
├── docs/
│   └── README.md            # Данный файл
└── assets/                   # Папка для изображений и иконок
```

## 🚀 Возможности

### Основные функции:
- ✅ Просмотр ленты видео с автоматической прокруткой
- ✅ Загрузка собственных видео
- ✅ Запись видео с веб-камеры
- ✅ Система фильтров для видео
- ✅ Лайки и просмотры
- ✅ Комментарии к видео
- ✅ Профиль пользователя с галереей
- ✅ Поиск по видео и хэштегам
- ✅ Система подписок
- ✅ Поделиться видео (WhatsApp, Telegram, Twitter, копирование ссылки)
- ✅ Тёмная/светлая тема
- ✅ Pull-to-refresh (повторное обновление при свайпе вниз)
- ✅ Автовоспроизведение видео
- ✅ Офлайн-режим (базовый)

## 📱 Использование

### Запуск локально:

1. Откройте папку проекта
2. Запустите локальный сервер (например, Python):
   ```bash
   python -m http.server 8000
   # или
   npx http-server
   ```
3. Откройте `http://localhost:8000`

### Первый запуск:

1. **Вход в систему**: Используйте любой email и пароль (мин. 6 символов)
2. **Создание видео**: 
   - Нажмите кнопку "+" в навигации
   - Выберите файл или запишите с камеры
   - Добавьте описание и хэштеги
   - Опубликуйте
3. **Просмотр профиля**: Нажмите на иконку профиля interno нижней

## 🎨 Архитектура кода

### AdvancedDataService
Отвечает за управление данными:
- Сохранение/загрузка видео (LocalStorage)
- Управление пользователем
- Операции с лайками, комментариями
- Поиск видео

### AdvancedViewRenderer
Отвечает за создание UI элементов:
- Рендеринг видео карточек
- Форматирование чисел и времени
- Создание модальных окон
- Уведомления (Toast)

### AdvancedApp
Основное приложение:
- Инициализация
- Управление событиями
- Навигация между экранами
- Логика записи видео

## 🔧 Функции для разработчика

### Добавить новый фильтр видео:

В `js/data-service.js` в массив `this.videoFilters`:
```javascript
{ id: 'new-filter', name: 'Название', class: 'filter-5' }
```

Затем добавить CSS в `css/feed.css`:
```css
.video-item.filter-5 video { filter: /* ваши стили */; }
```

### Добавить новый экран (View):

1. Добавить HTML в `index.html`:
```html
<div id="new-view" class="view">
    <!-- содержимое -->
</div>
```

2. Добавить навигационный элемент в `index.html`
3. Добавить обработчик в `js/app.js`

## 📊 LocalStorage ключи

- `reelgram_advanced_data` - массив видео
- `reelgram_advanced_auth` - данные текущего пользователя
- `reelgram_settings` - настройки приложения

## 🐛 Известные ограничения

- Видео хранятся как Data URLs (до 100MB), что ограничено памятью
- Для production нужен API сервер
- Нет синхронизации между вкладками браузера
- Камера требует HTTPS (кроме localhost)
